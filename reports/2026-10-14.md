## Problems solved

- **Docker reported 0 bytes reclaimable while containerd held 2.3 GB.** Root cause: Docker was using the containerd image store (`driver-type: io.containerd.snapshotter.v1`), so the images simply live there instead of `/var/lib/docker`. Nothing was orphaned; the disk was just undersized.
- **Repair script ran "successfully" inside the AdGuard VM but changed nothing.** Root cause: with 0 bytes free, the shell redirect created an empty file and bash executed it without error. Fix: pipe the script into bash from memory (`base64 -d | bash`) so no disk write is needed.
- **Grafana vanished.** Root cause: it had stopped when the disk filled, and a `docker container prune` removed the stopped container. Its data was in a named volume, so recreating from compose restored every dashboard.
